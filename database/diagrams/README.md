# Database diagrams

These editable Mermaid ER diagrams are **provisional logical drafts** derived from the supplied image ERD, current code, and 2026-10-23 meeting transcript. They are not yet migration-backed and must not be treated as the final physical schema. Preview these Markdown files in VS Code to render the Mermaid blocks.

Before acceptance, synchronize every entity, column, optionality, key, and relationship with the executable migration set and run the schema-vs-diagram review described in `../test-plan.md`.
